# NEXO-C

پیام‌رسان فارسی حرفه‌ای بر پایه Flask + SQLite (+ Flask-SocketIO) + PWA.

نسخه ارتقایافته از NEXO با برند **NEXO-C**، مالک ثابت، پنل مدیریت گروه/کانال متصل به API، و آمادگی اجرا روی هاست‌های Python مثل پارس‌پک.

## مالک اصلی

- نام کاربری مالک در کد ثابت است: **`arad_kr`**
- نیازی به متغیر محیطی `NEXO_ADMIN` نیست.
- ثبت‌نام یا ورود موفق با `@arad_kr` نقش `owner` می‌دهد / ارتقا می‌دهد.
- نقش مالک اصلی قابل تنزل، مسدودسازی یا حذف توسط مدیران دیگر نیست.

## اجرای محلی

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

پیش‌فرض پورت: **8000**  
آدرس: http://127.0.0.1:8000  
پنل مدیریت: http://127.0.0.1:8000/admin

## اجرا روی پارس‌پک / هاست Python

1. فایل‌ها را در ریشه اپ آپلود کنید (یا از همین ZIP استخراج کنید).
2. `requirements.txt` نصب شود.
3. متغیرهای محیطی پیشنهادی:

```
SECRET_KEY=<یک رشته تصادفی بلند>
PORT=8000
NEXO_DATA_DIR=/path/to/persistent/data
NEXO_SECURE_COOKIES=true
NEXO_OPENROUTER_KEY=   # اختیاری برای AI
```

4. دستور اجرا (Procfile موجود است):

```
web: gunicorn --worker-class gthread --workers 1 --threads 100 --timeout 120 --bind 0.0.0.0:${PORT:-8000} app:sio
```

اگر SocketIO در دسترس نباشد، `sio` به خود `app` اشاره می‌کند تا WSGI همچنان کار کند.

پورت از متغیر `PORT` خوانده می‌شود؛ در نبود آن مقدار پیش‌فرض کد **8000** است.

## امکانات اصلی حفظ‌شده و توسعه‌یافته

- پیام خصوصی، فایل/تصویر/ویدیو، پاسخ و فوروارد، واکنش، استیکر
- Stars، Premium، ماموریت‌ها، نشان‌ها
- NEXO AI، ربات‌ها، کارت فروشندگی، پیام‌های ذخیره‌شده
- گروه‌ها و کانال‌ها با API کامل (`channels_ext.py`):
  - عمومی/خصوصی، لینک دعوت با محدودیت و انقضا
  - درخواست عضویت و تأیید/رد
  - تنظیمات: فقط مدیران، حالت آهسته، ظرفیت، خوش‌آمد، قوانین
  - مدیریت اعضا: promote/demote/mute/kick/ban
  - نظرسنجی، موضوعات، آمار، تاریخچه فعالیت مدیران
- پنل مدیریت گروه/کانال در UI (منوی چت → «مدیریت گروه/کانال»)
- پنل مدیریت مرکزی (`/admin`)

## دیتابیس

- SQLite در مسیر `NEXO_DATA_DIR` یا کنار `app.py` (`nexo.db`)
- جداول افزونه به‌صورت additive ساخته می‌شوند؛ داده‌های قبلی حفظ می‌شوند.

## مشکلات شناخته‌شده / محدودیت‌ها

- زمان‌بندی انتشار پست کانال به worker پایدار نیاز دارد و به‌صورت کامل در این نسخه تضمین نشده است.
- بخشی از UI کانال (ویرایش پست پیشرفته، آمار رشد گرافیکی کامل) ساده نگه داشته شده و از APIهای موجود استفاده می‌کند.
- WebRTC / تماس صوتی-تصویری در این نسخه وجود ندارد.
